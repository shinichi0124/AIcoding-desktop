## 已做到（相对计划 + 用户后加）

- 同一套聊天 chrome；Tab = 六模组；不 iframe 官方 UI。
- 设置：CLI 行 + API 行 + 验证连接（`--version`）；无 AI Review。
- 打开终端 = 当前模组可见 cmd，cwd=工作区。
- 日志：`%LOCALAPPDATA%\AI-Coding-Desktop\logs`，IMPORTANT 仅 WARN+，ALERT `!!! `，密钥脱敏，LATEST 指针。
- ACP 读循环 `read(65536)`，禁止 `read(1)`。
- 用户后加：官网 logo Tab、图标按钮、G+`Coding platform`、G+`ai` 快捷方式/任务栏图标、设置右上角关闭、关窗到托盘 radio、GitHub 版权行。

## Bug / 风险（未在本轮改产品逻辑）

1. **DeepSeek 聊天未接通** — 点发送会得到「等宿主映射」说明，不是 harness 对话。
2. **Codex `app-server` / Claude `--acp` 不一定是本 `AcpClient` 方言** — 失败应只记 IMPORTANT，不要假装聊上了。
3. **会话无删除** — 计划 1.4 有 delete；UI 只有列表/新建/点选 load。
4. **设置无「浏览」** — 计划 CLI 行有浏览；现在只能手贴路径。
5. **API 密钥进 `~\.ai-coding-desktop\config.json`** — 计划写各家原生凭据；启动时只注入环境变量，没有写 `~/.dsh/.credentials.yaml` / `~/.qwen/settings.json`。
6. **无模型/effort 条** — 计划「引擎暴露什么显示什么」；现在不画假开关（对），但也没有真控件。
7. **`pywebview.create_window(icon=)` 本机不支持** — 任务栏必须 `WM_SETICON`（v0.1.5 已修）。
8. **无 supervisor** — 引擎崩了不会自动拉；ALERT 靠 agent_exit。
9. **`health.jsonl` 随 `/api/health` 写入**（前端约 4s），不是独立 5s 时钟；够用但不是大纲原文。
10. 父项目 README 曾写「整合前端尚未开建」——本轮文档已改。
